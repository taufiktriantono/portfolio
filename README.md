# Taufik Triantono — Portfolio

Personal backend and platform engineering portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Editable content lives in:

- `src/data/profile.ts`
- `src/data/projects.ts`
- `src/data/experience.ts`

Replace placeholder experience copy and verify the email/LinkedIn URLs before deployment.

## Deploy

Import this directory into Vercel, then add `taufiktriantono.railzway.com` as its custom domain.
